Trouvaille

Trouvaille est une application personnelle, utilisée par une seule personne, sur son propre ordinateur.

Elle part d’images d’inspiration mode pour aider à trouver des vêtements de seconde main similaires :

  • analyse d’une image d’inspiration (type de pièce, couleurs, style) ;
  • génération de recherches sur des sites de seconde main ;
  • mood board des inspirations, y compris l’import de mes propres tableaux Pinterest ;
  • wishlist des pièces repérées.

L’application n’est pas distribuée au public et ne collecte aucune donnée sur d’autres personnes.
